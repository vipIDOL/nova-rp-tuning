# NOVA RP Auto Tuning

Калькулятор тюнинга для NOVA RP: гос-цена авто, скидка мастерской, чип-тюнинг по уровням, drift mod и 12 позиций внешнего вида. Итог пересчитывается мгновенно, смету можно скопировать одной кнопкой.

![Превью калькулятора](og.png)

## Что внутри

- **Две темы** — тёмная в стиле NOVA RP (графит + золото, карта города на фоне) и светлая «Studio». Выбор запоминается.
- **Мгновенный пересчёт** — цена, скидка 50/25/0%, уровни двигателя, тормозов, подвески и КПП.
- **Смета на виду** — итог, разбивка по статьям и экономия на скидке.
- **Копирование сметы** — готовый текст для Discord.
- **Мобильная версия** — от 360 px.
- **Один файл** — без сборки, зависимостей и внешних запросов: шрифт встроен, карта нарисована SVG, работает офлайн.
- **Счётчик** — глобальный, в футере; считает сессии, где меняли гос-цену.

## Публикация на GitHub Pages

Нужен аккаунт GitHub и публичный репозиторий (Public — иначе бесплатные Pages не включатся).

### Быстрый способ: скрипт

В корне проекта, рядом с папкой `site`, лежит `setup-github.ps1`. Он подставит ваш ник в OG-теги, сделает commit и push, а потом откроет настройки Pages.

1. Запустите PowerShell в корне проекта.
2. Выполните:

   ```powershell
   .\setup-github.ps1
   ```

3. Введите username и имя репозитория — скрипт откроет страницу создания.
4. Создайте **пустой** репозиторий (без README, .gitignore и лицензии).
5. Вернитесь в консоль и нажмите Enter.
6. В открывшихся настройках: **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

Через 1–2 минуты сайт будет доступен:

```text
https://USERNAME.github.io/nova-rp-tuning/
```

### Вручную через сайт GitHub

1. [github.com](https://github.com) → **New repository**.
2. Имя, например `nova-rp-tuning`, видимость **Public** → **Create repository**.
3. **Add file → Upload files**. Перетащите:
   - `index.html`
   - `og.png`
   - `404.html`
   - `robots.txt`
   - `LICENSE`
   - `README.md`
   - `.nojekyll` (скрытый файл; если не видно — пропустите, не критично)
   - папку `server` целиком (опционально)
4. **Commit changes**.
5. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
6. Откройте `index.html` на GitHub → карандаш → замените в двух мета-тегах `USERNAME` и `REPO` на свои:

   ```html
   <meta property="og:image" content="https://USERNAME.github.io/REPO/og.png">
   <meta property="og:url" content="https://USERNAME.github.io/REPO/">
   ```

   Это нужно, чтобы ссылка в Discord разворачивалась с обложкой. Без замены сайт работает, но превью не подтянется.

## Локальный просмотр

Откройте `index.html` двойным щелчком. Мобильную версию удобно проверять в DevTools → Toggle device toolbar.

## Где менять цены

В конце `index.html`, в блоке `<script>`:

- `TIERS` — названия и размер скидки (50/25/0%);
- `UNITS` — двигатель, тормоза, подвеска, КПП: коэффициенты уровней;
- `LOOKS` — 12 позиций внешнего вида и их проценты;
- `DEFAULT` — стартовые значения при загрузке и после «Сбросить».

Все суммы считаются от гос-цены авто, поэтому менять абсолютные числа не нужно — только коэффициенты.

## Глобальный счётчик

В футере — «Калькулятором воспользовались N раз». Считается сессия, в которой меняли гос-цену; простые открытия страницы не учитываются.

GitHub Pages — статический хостинг: страница не может записать файл на сервере. Поэтому «counter.txt» возможен только на своём сервере.

**По умолчанию** счётчик ходит в бесплатный сервис abacus (одно анонимное число, без cookie). Если сервис недоступен, показывается последнее значение из `localStorage`.

**Свой `counter.txt`:** в папке `server/` лежит мини-сервер на Node без зависимостей.

```bash
node server/counter.js      # http://localhost:8787
```

API: `GET /count` → `{ "count": 12 }`, `POST /hit` → `{ "count": 13 }`.

Поднимите его на Render, Railway, VPS или любом Node-хостинге, затем укажите адрес в `index.html`:

```js
const COUNTER_API = 'https://ваш-сервер';
```

Нюансы:

- для постоянного хранения файла нужен диск (Render Disk, папка на VPS), иначе при перезапуске счётчик обнулится;
- сервер рассчитан на один экземпляр; при нескольких репликах нужен общий диск или база;
- GitHub Pages не запускает Node — сервер живёт отдельно, страница остаётся статичной.

## Свой домен (опционально)

**Settings → Pages → Custom domain**, впишите домен и добавьте у регистратора CNAME на `USERNAME.github.io`. HTTPS включится автоматически после проверки DNS.
